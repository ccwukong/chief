# chief — E2E Test Plan

Companion to [dev-plan.md](dev-plan.md). Every task in §7 of the dev plan has at least one test case here.
The workflow that uses this plan is in [../AGENTS.md](../AGENTS.md).

## 1. Approach

- **Runner:** Playwright Test for every case. CLI and API cases need no browser; Phase 6 cases drive
  the real web UI in Chromium against a real `chief serve`.
- **Black box:** tests run the `chief` CLI (`node packages/chief/src/cli.ts`) or call the HTTP API, and
  assert on output, exit codes and `--json` data. They do not import engine code.
- **Isolation:** each test has its own `CHIEF_HOME` and working directory under `e2e/.tmp/`.
- **Browser cases run one at a time per file** (two visible windows at most), because they drag
  with a real mouse; palette drops and hand-drawn connections are retried only when nothing appeared.
- **No MCP setup in tests.** chief has no MCP configuration; tests change what the fake CLI
  reports (`FAKE_CLAUDE_MCP_LIST`) instead of registering servers in chief.
- **Agent CLI:** `e2e/fixtures/fake-claude.ts` stands in for Claude Code. It emits the same
  `stream-json` shape recorded in the 0.1 spike, supports sessions, `--resume`, SIGINT and usage, and
  logs every invocation so tests can assert on the flags chief passed. Its replies are scripted from
  the prompt with a `<fake>{…}</fake>` directive.
- **Real CLI cases** are tagged `@real`, run only with `CHIEF_E2E_REAL=1`, use the cheapest model and
  never write to a real service.
- **Scripts** run in the real macOS sandbox; nothing about the sandbox is faked.
- **Desktop cases** (Phase 10) drive the packaged Electron app with Playwright's `_electron`, with the
  same fake agent CLI in the sidecar's environment. They need `npm run build` and `npm run build:desktop`
  first, and they run headed: a window is the point.

## 2. How to run

```sh
npx playwright test -g "E9.22-1|E9.21-1"   # the cases a change touches (the default, see AGENTS.md)
npm run e2e                          # all phases (full regression): only when the user asks for it
CHIEF_E2E_HEADLESS=1 npm run e2e     # same, without a visible browser window
npx playwright test e2e/phase-1      # one phase
CHIEF_E2E_REAL=1 npx playwright test --grep @real   # real Claude Code cases
```
